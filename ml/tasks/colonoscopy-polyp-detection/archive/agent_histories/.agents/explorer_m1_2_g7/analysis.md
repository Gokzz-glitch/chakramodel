## 1. Executive Summary & Root Cause Synthesis

An exhaustive, line-by-line audit of the model evaluation pipeline was conducted across `src/verify_strict.py`, `local_eval.py`, helper scripts, and Colab notebooks. The investigation identified the precise technical root cause of the evaluation failure observed in Google Colab:

```text
Copying files directly (skipping the slow search)...
❌ CRITICAL: Could not find the weights at /content/drive/MyDrive/chakra_transformer_best.pth
❌ CRITICAL: Could not find the zip at /content/drive/MyDrive/chakramodel_data_scripts.zip
unzip:  cannot find or open /content/chakramodel_data_scripts.zip, /content/chakramodel_data_scripts.zip.zip or /content/chakramodel_data_scripts.zip.ZIP.
FileNotFoundError: [Errno 2] No such file or directory: '/content/src/verify_strict.py'
```

### Core Root Causes:
1. **Subfolder Omission in Google Drive Direct Copy:**  
   The Colab setup script attempted a "direct copy" looking for `/content/drive/MyDrive/chakra_transformer_best.pth` and `/content/drive/MyDrive/chakramodel_data_scripts.zip` at the **root** of `MyDrive`. However, the synced project files resided in a subfolder: either `/content/drive/MyDrive/chakramodel/` or `/content/drive/MyDrive/chakramodel_collab/` (as generated by `setup_colab.py` line 6). Because the root lookup failed, the copy to `/content/` was skipped.
2. **Unzip Failure Cascading to Missing Script:**  
   Because the zip copy failed, `/content/chakramodel_data_scripts.zip` did not exist. The subsequent shell command `!unzip -q /content/chakramodel_data_scripts.zip -d /content/` threw `cannot find or open ...`. Consequently, `src/verify_strict.py` was never placed in `/content/src/verify_strict.py`.
3. **Jupyter Shell Working Directory Disconnect (`!cd` vs `%cd`):**  
   In Colab, executing shell commands via `!cd <dir>` runs in an ephemeral subshell; the parent notebook kernel remains at `/content`. If a script or user attempts `!python src/verify_strict.py` or `!python /content/src/verify_strict.py` from `/content`, Python looks for `/content/src/verify_strict.py`. Because the unzipping failed (or if the repo was cloned to `/content/chakramodel/`), the file path does not exist, raising `FileNotFoundError: [Errno 2] No such file or directory: '/content/src/verify_strict.py'`.
4. **Severe Archive Hierarchy Mismatch:**  
   - `chakramodel_data_scripts.zip` packages files with relative paths `src/...` and `data/...`, but contains **no model weights** (only `src/yolov8x.pt`).
   - `chakramodel-weights.zip` packages weights flat at the root: `['best.pt', 'chakra_transformer_best.pth', 'conformal_calibration.json']` with **no `weights/` subfolder**.  
   - Both `src/verify_strict.py` (line 103) and `local_eval.py` (line 149) strictly mandate a `weights/` subdirectory: `root / "weights" / "chakra_transformer_best.pth"`. Even if unzipped into `/content/`, the script crashes because the weights are extracted to `/content/chakra_transformer_best.pth`, not `/content/weights/chakra_transformer_best.pth`.
5. **Widespread Hardcoded Values & Environment Assumptions:**  
   `local_eval.py` hardcodes `device = torch.device('cuda')` (crashing on non-CUDA machines), hardcodes base directory detection to three specific paths, and falls back to a Windows drive path `m:/chakramodel` on Linux. `src/verify_strict.py` previously contained `torch.cuda.is_available = lambda: False` which disables GPU acceleration entirely, and hardcodes fallback dataset paths to CVC-ColonDB and CVC-300 under `root / "data/..."`.

## 5. Cross-Platform Discrepancies: Windows Local vs Google Colab Cloud GPU

### A. Filesystem Case Sensitivity (NTFS vs ext4)
- **Windows (NTFS):** Case-insensitive. A file named `100.PNG` is matched by `images_dir.glob("*.png")`. A mask path check for `100.png` succeeds even if the file on disk is `100.PNG`.
- **Linux (Colab ext4):** Strictly case-sensitive. `images_dir.glob("*.png")` ignores `.PNG`, `.JPG`, `.JPEG`. In `src/verify_strict.py`, line 37:
  ```python
  image_paths = sorted(list(images_dir.glob("*.png")) + list(images_dir.glob("*.jpg")) + list(images_dir.glob("*.tif")))
  ```
  If datasets on Linux contain uppercase extensions, `image_paths` evaluates to an empty list `[]`. The loop completes with 0 images evaluated, producing NaN averages.

### B. Google Drive FUSE Layer Latency
In Colab, mounting Google Drive (`/content/drive/MyDrive`) creates a user-space virtual filesystem (FUSE).
- Sequential reads of large binary files (e.g. 1.2GB `chakra_transformer_best.pth`) over FUSE run through network throttling and can take 2–5 minutes, or cause kernel timeouts.
- File-walking functions like `Path.rglob('*')` (in `local_eval.py` line 106) perform remote directory listing calls for every subfolder. When run on Google Drive, this can freeze the notebook for 10+ minutes.
- **Sync Latency:** When files are copied to `J:\My Drive` on Windows, the Google Drive desktop client must complete the upload to Google Cloud before Colab's `/content/drive/MyDrive` can see them. If a user runs Colab immediately after running `setup_colab.py`, files appear missing (0 bytes or non-existent).

### C. Jupyter Kernel Working Directory Mechanics (`!cd` vs `%cd`)
- In IPython/Colab, the `!` prefix spawns a child subshell:
  ```bash
  !cd /content/drive/MyDrive/chakramodel
  ```
  The child process changes directory and terminates immediately. The persistent Jupyter Python kernel remains in `/content`.
- When the next cell executes:
  ```bash
  !python src/verify_strict.py
  ```
  It executes relative to `/content`. Unless `src/verify_strict.py` exists at `/content/src/verify_strict.py`, execution crashes with `FileNotFoundError`.
- Only the IPython magic command `%cd` alters the working directory of the active Python kernel.

## 7. Concrete Code Fixes & Robust Architectural Recommendations

To make the evaluation architecture completely dynamic, robust, and environment-agnostic across Windows, Linux, Google Colab, and Kaggle, the following concrete implementations are provided.

### Fix 1: Fully Dynamic, Environment-Agnostic `src/verify_strict.py`

This implementation removes all hardcoded paths, eliminates redundant weight loading, supports dynamic CLI arguments and environment variables, incorporates case-insensitive file discovery, and prevents unchecked file crashes:

```python
import os
import sys
import argparse
import hashlib
from pathlib import Path
import cv2
import numpy as np
import torch

# 1. Dynamic Project Root Resolution
def find_project_root(explicit_root=None) -> Path:
    if explicit_root and Path(explicit_root).exists():
        return Path(explicit_root).resolve()
    env_root = os.environ.get("CHAKRAMODEL_ROOT")
    if env_root and Path(env_root).exists():
        return Path(env_root).resolve()
    # Search upwards from current file for project anchor files
    current = Path(__file__).resolve().parent
    for parent in [current] + list(current.parents):
        if (parent / "src" / "chakranet_segmenter.py").exists() or (parent / "weights").exists():
            return parent
    return Path.cwd().resolve()

PROJECT_ROOT = find_project_root()
sys.path.insert(0, str(PROJECT_ROOT / "src"))
sys.path.insert(0, str(PROJECT_ROOT))

from ultralytics import YOLO
from chakranet_segmenter import ChakraNet
from metrics_engine_v2 import MetricsEngineV2

IMAGE_EXTENSIONS = {".png", ".jpg", ".jpeg", ".tif", ".tiff", ".bmp"}

def md5(fname: Path) -> str:
    if not fname.exists():
        return "FILE_NOT_FOUND"
    hash_md5 = hashlib.md5()
    with open(fname, "rb") as f:
        for chunk in iter(lambda: f.read(65536), b""):
            hash_md5.update(chunk)
    return hash_md5.hexdigest()

def find_file_candidates(root: Path, filename: str, subdirs=("weights", "")) -> Path:
    for subdir in subdirs:
        candidate = root / subdir / filename if subdir else root / filename
        if candidate.exists():
            return candidate
    # Fallback to standard Colab paths
    colab_candidates = [
        Path("/content/drive/MyDrive/chakramodel") / "weights" / filename,
        Path("/content/drive/MyDrive/chakramodel_collab") / "weights" / filename,
        Path("/content/weights") / filename,
        Path("/content") / filename,
    ]
    for c in colab_candidates:
        if c.exists():
            return c
    return root / "weights" / filename

def get_device(requested: str = None) -> torch.device:
    if requested:
        return torch.device(requested)
    if torch.cuda.is_available():
        return torch.device("cuda")
    if hasattr(torch.backends, "mps") and torch.backends.mps.is_available():
        return torch.device("mps")
    return torch.device("cpu")

def verify_dataset(dataset_name: str, images_dir: Path, masks_dir: Path, yolo_model, segmenter, metrics_engine, device: torch.device):
    print(f"\n{'='*60}\nVERIFYING DATASET: {dataset_name}\n{'='*60}")
    if not images_dir.exists():
        print(f"[ERROR] Images directory not found: {images_dir}")
        return None
    if not masks_dir.exists():
        print(f"[ERROR] Masks directory not found: {masks_dir}")
        return None

    # Case-insensitive image discovery
    image_paths = sorted([p for p in images_dir.iterdir() if p.suffix.lower() in IMAGE_EXTENSIONS])
    print(f"Total images found: {len(image_paths)}")
    if not image_paths:
        print(f"[WARN] No valid images discovered in {images_dir}")
        return None

    # Index masks case-insensitively by stem
    mask_lookup = {}
    for m in masks_dir.iterdir():
        if m.suffix.lower() in IMAGE_EXTENSIONS:
            mask_lookup[m.stem.lower()] = m

    results = {k: [] for k in ["Dice", "mIoU", "wF-measure", "S-measure", "E-measure", "MAE"]}

    for i, img_path in enumerate(image_paths):
        mask_path = mask_lookup.get(img_path.stem.lower())
        if not mask_path:
            continue

        img_bgr = cv2.imread(str(img_path))
        gt_mask = cv2.imread(str(mask_path), cv2.IMREAD_GRAYSCALE)
        if img_bgr is None or gt_mask is None:
            continue

        img_resized = cv2.resize(img_bgr, (448, 448))
        yolo_results = yolo_model(img_resized, verbose=False, device=str(device))[0]
        c_mask = np.zeros((448, 448), dtype=np.uint8)

        if len(yolo_results.boxes) > 0:
            boxes = sorted(yolo_results.boxes, key=lambda b: b.conf[0].item(), reverse=True)
            box = boxes[0].xyxy[0].cpu().numpy()
            x1, y1, x2, y2 = map(int, box)
            w_box, h_box = x2 - x1, y2 - y1
            px, py = int(0.25 * w_box), int(0.25 * h_box)
            px1, py1 = max(0, x1 - px), max(0, y1 - py)
            px2, py2 = max(0, min(448, x2 + px)), max(0, min(448, y2 + py))

            if px2 > px1 and py2 > py1:
                roi_crop = img_resized[py1:py2, px1:px2]
                seg_roi_mask, _, _, _ = segmenter.segment_roi(roi_crop, threshold=0.45)
                if seg_roi_mask is not None:
                    seg_roi_mask = cv2.resize(seg_roi_mask, (px2 - px1, py2 - py1), interpolation=cv2.INTER_NEAREST)
                    c_mask[py1:py2, px1:px2] = seg_roi_mask

        gt_resized = cv2.resize(gt_mask, (448, 448), interpolation=cv2.INTER_NEAREST)
        c_bin = (c_mask > 127).astype(np.uint8)
        gt_bin = (gt_resized > 127).astype(np.uint8)

        metrics = metrics_engine.compute_all(c_bin, gt_bin)
        for k in results.keys():
            results[k].append(metrics[k])

        if (i + 1) % 50 == 0 or (i + 1) == len(image_paths):
            print(f"[{i + 1}/{len(image_paths)}] Processed. Current Avg Dice: {np.mean(results['Dice']):.4f}")

    print(f"\n[DONE] {dataset_name} | Evaluated Images: {len(results['Dice'])}")
    for k in results.keys():
        print(f"Final True Average {k}: {float(np.mean(results[k])):.4f}")
    return {k: float(np.mean(v)) for k, v in results.items()}

def main():
    parser = argparse.ArgumentParser(description="ChakraModel Strict Evaluation")
    parser.add_argument("--root", type=str, default=None, help="Project root directory")
    parser.add_argument("--weights", type=str, default=None, help="Path to chakra_transformer_best.pth")
    parser.add_argument("--yolo-weights", type=str, default=None, help="Path to best.pt")
    parser.add_argument("--data-root", type=str, default=None, help="Path to data directory")
    parser.add_argument("--dataset-name", type=str, default=None, help="Specific dataset name")
    parser.add_argument("--device", type=str, default=None, help="Execution device (cuda/cpu)")
    args = parser.parse_args()

    root = find_project_root(args.root)
    device = get_device(args.device)
    print(f"Project Root Resolved: {root}")
    print(f"Execution Device: {device}")

    # Discover weights dynamically
    seg_weight_path = Path(args.weights) if args.weights else find_file_candidates(root, "chakra_transformer_best.pth")
    yolo_weight_path = Path(args.yolo_weights) if args.yolo_weights else find_file_candidates(root, "best.pt")

    print(f"Segmenter Checkpoint: {seg_weight_path} (Exists: {seg_weight_path.exists()}, MD5: {md5(seg_weight_path)})")
    print(f"YOLO Checkpoint: {yolo_weight_path} (Exists: {yolo_weight_path.exists()}, MD5: {md5(yolo_weight_path)})")

    if not seg_weight_path.exists() or not yolo_weight_path.exists():
        print("[ERROR] Required checkpoint weights not found! Aborting.")
        sys.exit(1)

    yolo_model = YOLO(str(yolo_weight_path))
    yolo_model.to(str(device))

    # Single-pass weight loading (avoids double memory spike)
    segmenter = ChakraNet(img_size=(384, 384), device=str(device), weights_path="skip")
    segmenter.model.to(device)

    sd = torch.load(seg_weight_path, map_location=device, weights_only=True)
    sd_fixed = {k.replace("_orig_mod.", "").replace("module.", ""): v for k, v in sd.items()}
    res = segmenter.model.load_state_dict(sd_fixed, strict=False)
    print(f"ChakraNet Weights Loaded. Missing: {len(res.missing_keys)}, Unexpected: {len(res.unexpected_keys)}")

    metrics_engine = MetricsEngineV2()

    # Dynamic dataset resolution
    data_base = Path(args.data_root) if args.data_root else root / "data"
    env_name = args.dataset_name or os.environ.get("VERIFY_DATASET_NAME")
    env_root = os.environ.get("VERIFY_DATASET_ROOT")

    if env_name and env_root:
        d_root = Path(env_root)
        verify_dataset(env_name, d_root / "images", d_root / "masks", yolo_model, segmenter, metrics_engine, device)
    else:
        datasets = [("CVC-ColonDB", "cvc-colondb"), ("CVC-300", "cvc-300")]
        for dname, dfolder in datasets:
            d_path = data_base / dfolder
            verify_dataset(dname, d_path / "images", d_path / "masks", yolo_model, segmenter, metrics_engine, device)

if __name__ == "__main__":
    main()
```

```python
    candidates = [
        Path.cwd(),
        Path(__file__).resolve().parent,

        Path('/content/chakramodel'),
        Path('/content'),

    ]

# Model and Dataset definitions remain clean and standard
# compute_metrics removes debug print spam:
def compute_metrics(model, loader, device):
    model.eval().to(device)
    dices, ious, precs, recs = [], [], [], []
    total_batches = len(loader)
    with torch.no_grad():
        for batch_idx, (imgs, masks) in enumerate(loader):
            imgs = imgs.to(device)
            logits = model(imgs)
            probs = torch.sigmoid(logits).cpu().numpy()
            gts = masks.numpy()
            for i in range(len(probs)):
                p = (probs[i, 0] > 0.5).astype(np.float32)
                g = (gts[i, 0] > 0.5).astype(np.float32)
                tp = (p * g).sum()
                fp = (p * (1.0 - g)).sum()
                fn = ((1.0 - p) * g).sum()
                dices.append((2.0 * tp + 1e-6) / (2.0 * tp + fp + fn + 1e-6))
                ious.append((tp + 1e-6) / (tp + fp + fn + 1e-6))
                precs.append((tp + 1e-6) / (tp + fp + 1e-6))
                recs.append((tp + 1e-6) / (tp + fn + 1e-6))
            if (batch_idx + 1) % 50 == 0 or (batch_idx + 1) == total_batches:
                print(f"[{batch_idx + 1}/{total_batches}] Batch Evaluated. Current Dice: {np.mean(dices):.4f}")
    return {'dice': float(np.mean(dices)), 'iou': float(np.mean(ious)),
            'precision': float(np.mean(precs)), 'recall': float(np.mean(recs))}
```
